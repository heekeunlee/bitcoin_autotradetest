실거래 전환은 권하지 않음
4번의 백테스트 중 단순 보유를 이긴 버전이 하나도 없습니다. dry_run: false + 실제 API 키로 바꾸는 순간 원금 손실 위험이 실제로 발생하니, 지금 성과로는 전환할 이유가 없습니다.
